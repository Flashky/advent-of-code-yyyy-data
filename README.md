# 💾 Advent of Code {year} Data

## ⚙️ Quick Start

Scaffold your Advent of Code repository for Java in two easy steps:

1.  ▶️ Run the [AoC Repository Creation](https://github.com/Flashky/advent-of-code-yyyy/actions/workflows/create-repo.yml) workflow. 
2.  Remove these setup instructions from the ``README.md``.

The workflows will create two repositories:

- **advent-of-code-yyyy**: for the solutions (public)
- **advent-of-code-yyyy-data**: for the inputs (private)

**Enjoy your new Advent of Code edition!**

---

Data repository for [advent-of-code-{year}](https://github.com/Flashky/advent-of-code-{year}) solutions repository.

## Update local repository

Use the following command to update the local repo if there are any remote changes:

```bash
git submodule update --recursive --remote
```

## Re-attach local repository

If the local repo becomes detached, execute:

```bash
git checkout master
```
